# ER-HFC 补充实验

版本 `er-hfc-development-v1`。本轮检验现有模块叠加后的净收益，并用同一冻结表征改变短前缀样本量与读出自由度。当前三队列版本用于开发。E04 的结果在新队列与冻结接收记录齐备后单列。现有停止任务免重跑。

## 资产与主实验数据

源为 Forenzo 已锁定的 25 人、五份 CSP/LDA 划分。PCA、EA 参考、缩放和 MDM 原型只由各折训练成员计算。CSP/LDA 的源留出 BA、AUC 与归档逐人锚点核对。从同一批源训练数据重新计算的 MDM 为读出机制复查。基础模型预训练是否覆盖测试队列仍待证实。

| 队列 | 人数 | 会话 | 预先指定的用途 |
|---|---:|---:|---|
| Stieger 第 3、4 场 | 62 | 124 | 真实原始试次位置，开发、因子消融、前提示休息、标签污染及长前缀 |
| OpenBMI 第 1、2 日 | 54 | 108 | 排程混杂下的敏感性。逐日、逐人测位置模板与两日重复 |
| Cho2017 | 52 | 52 | 依发布顺序回放。物理顺序未经独立验证，长前缀结果按顺序敏感性解释 |

同一研究的不同会话属于同一人。三个队列分别估计。Stieger [−1,0) 秒是提示前窗，[0,1) 秒是目标可见窗，原始缓存有 [2,3) 秒可用反馈窗时另做同试次窗口比较。不能从提示期模型的判别力单独推定皮层想象机制。

## E01–E04 核心

| 实验 | 执行设计 | 主要反证 |
|---|---|---|
| E01 | B20 同源同试次比较冻结、普通 EA、先验 EA、仅截距、普通 EA+截距、S1+S2、matched MAP、原 ERFC、拟议双门控。Stieger 第 4 场、CSP Fold 1 完整 2×2×2 因子。无标签休息独立预算比较冻结、休息 EA、休息截距与组合。 | 同锚下完整框架不优于 S1+S2。S3 有保护但同时损失纠错。 |
| E02 | 同一 91 维源切空间 PCA 固定子空间，用 d=0、1、2、4、8、16、32、64、Full 的嵌套读出。全模型共享损失、惩罚与最大迭代。主面使用 B=0、4、8、12、16、20、32、64、128 中可保持同一后段者。 | 同幅度对照不保留低维优势，或者其方向依赖队列、架构。 |
| E03 | 同一原始 MAP 提案。比较无残差、直接更新、随机、置信度、幅度匹配收缩、LOO、信赖域、原 ERFC 与拟议双门控。提案与外部架构选择均固定。 | BA 下滑、严重损失不降，或同更新数与幅度的对照达到同等表现。 |
| E04 | 准备了封存接收入口。预先固定 CSP、B20、完整拟议 ER-HFC 对 S1+S2，配套对 matched MAP 的保护检验。只有登记、独立性与数据包指纹齐备时启动。 | 外部 BA、非劣效或保护条件达不到冻结判据。 |

S1 用 32 个源先验等效权重合并目标前缀协方差，再把目标输运至固定源空间。普通 EA 使用同一源输出空间与零先验。S2 为平衡逻辑损失的单截距。缺少两手时保留原阈值。S3 的候选是原 ERFC 匹配核的低秩残差，使用 8 个源白化切空间坐标。原归档求解器采用同一 MAP、90% 目标收益保留和支持零空间。拟议双门控先要求严格重拟合的 LOO 平衡 NLL 收益 >0，再使用同一逐试次原 ERFC 校正并限制至 ±0.5 logit。LOO 的 EA、截距、MAP 在每个训练子集上重新拟合。新的冻结编码器与锚点使该结果属于新协议适配。

E02 的 d=0 保留 S1 的源读出。d=1 加截距，d=2 加正尺度，随后增加源固定 PCA 方向。Full 更新全部 93 个读出参数。名义参数与正则化 Fisher 有效维度单列。没有把完整读出更新当作完整网络微调。控制实验对 d4、d32、Full 等幅下调到同一个前缀 logit RMS。B0 和缺类条件保留固定回退。

## E05–E12 扩展

| 实验 | 本版执行范围 |
|---|---|
| E05 | 重用 E02 训练。Stieger 第 4 场固定原始第 129 位后的同一未来，保留每手至少 8 条及总计至少 20 条的可评估会话。报告 d32−d4 持续转折的配对 bootstrap 区间分布及无转折概率。Cho 的 B128 是发布顺序复查。 |
| E06 | 所有候选的输入是支持前缀统计。外层留整队列，内层留开发队列选择岭惩罚。与固定 d4、预算、置信度、可用时的 LOO 规则及 oracle 比较。对严重负迁移另做 B 与 B+有效维度的留库风险比较。 |
| E07 | Stieger 第 4 场 CSP Fold 1，B20。0%、10%、20%、30% 污染，同一人、同一次数、同一掩码供所有方法。0% 一次，其他三次。 |
| E08 | Stieger 和 OpenBMI B20 固定适配状态，随后各按原始位置切三个连续窗。OpenBMI 为有排程风险的时间条件。 |
| E09 | Stieger 第 3、4 场，MDM Fold 1、3，B8/20/64，alpha=0/.25/.50/.75/1。压力条件只重加权同一组真实相邻配对，20/50/80% 右手、等效质量 10，具备可交换支持时做 16 次按运行段、下一手别及前缀半段的休息配对打乱。 |
| E10 | 精确特征重复、试次 ID、源划分、原始机会、事件编码、OpenBMI 跨日重复、从其他受试者位置预测、不同时相同试次 AUC 及查询标签扰动测试。没有真实刺激时钟的条目仍保留该限制。 |
| E11 | CSP/LDA 与协方差 MDM 在同输入、同 B/d、匹配源折上做配对复查。已核查到 EEGNet 权重和 REVE 特征存在。原始给定输入的同试次窗口和基础模型预训练谱系未完全贯通，神经网络全量回放列为待接入。 |
| E12 | 记录 CPU 拟合和在缓存上评分的增量时间、峰值 RSS、显存快照、支持覆盖、参数与有效维度。按相同 80%/95% 覆盖比较随机与置信度拒识。主动指令错误率可估，空闲误启动需真实空闲标注。 |

同一前缀与未来的矩阵见 `EXPERIMENT_MATRIX.csv`。主矩阵的共同未来起点为 Stieger 和 OpenBMI 的第 65 位、Cho 的第 129 位。E08、E05 和 E04 分别预先定义自己的共同未来，结果按协议分别汇总。

## 候选外部队列与阶段

Zhou 7-day 的公开 v1.0.3 资料列 20 人、7 日及兼容运动区导联。准备前核对事件与实际刺激、许可证、原资助/队列身份及既往使用。固定后用独立发布序列选择，保留所有受试者分母。20 人的精度由人员层区间决定。已有 Pan2025 方案采用不同的静息参考终点，其开发与使用边界待复核，当前不进入 E04。[Zhou Dataset](https://www.nemar.org/dataset/nm000237?v=v1.0.3)

Phase 0 做资产、哈希和泄漏检查。Phase 1 做同数据真实小试与断点。Phase 2 运行 E01、E02、E03、E10。Phase 3 在独立数据就绪后单独运行。Phase 4 与 Phase 5 默认运行已具备数据的扩展、工程及报告。预注册停止只约束历史科学任务，新协议有独立版本，历史结果不作为训练目标或外部验证。
